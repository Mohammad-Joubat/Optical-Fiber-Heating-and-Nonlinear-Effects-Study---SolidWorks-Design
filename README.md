# Project Overview 

This project involves the design of a physical system using SolidWorks (CAD) software for conducting an experiment in fiber optics. The system's purpose is to allow for the examination of light propagation in a Multi-Mode Optical Fiber (MMF) while it is subjected to both mechanical stress (due to coiling) and thermal load (heating).The work includes:Precise engineering design of the housing, the winding spool, and the fiber guiding mechanisms.Creation of controlled conditions for heating the coiled region to a temperature of approximately $\mathbf{40^{\circ}C}$.Establishing a foundation for the investigation of nonlinear effects influenced by thermal and mechanical stress in the fiber.
